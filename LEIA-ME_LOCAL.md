# Ver o sistema no seu computador

1. Instale o Node.js (versão LTS) em https://nodejs.org, se ainda não tiver.
2. Extraia o zip e abra a pasta `conectas`.
3. No Supabase (SQL Editor), rode o arquivo `supabase/TUDO_PENDENTE_0002_a_0009.sql` uma vez.
4. Dê dois cliques em `iniciar.bat`. O navegador abre em http://localhost:3000.
5. Entre com o usuário criado em Authentication > Users no Supabase (o primeiro usuário vira administrador).

Para parar, feche a janela preta. A tela de login usa o seu banco real do Supabase.
